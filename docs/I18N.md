# Translation (i18n)

Veilleuse is written in French. **French is the source language**: every text stays in the code, in French, exactly
as before. When the game runs in English, each French string is looked up, as is, in an English catalog
(`French → English`, exact match). A missing entry falls back to the French text.

- Code: `src/i18n/index.ts` (API), `src/i18n/en/*.ts` (catalogs), `src/i18n/manifest.json` (files that must be fully
  translated).
- Language: `G.settings.language` (`'fr' | 'en'`, default from the browser), the « Langue / Language » row at the top
  of the options (applied immediately), or `?lang=en` / `?lang=fr` in the URL (for this visit; used by tests and links).
- Tooling: `node tools/i18n-missing.mjs`, `tests/i18n.test.ts`, and the playtest bot (`lang=en` in its query lists the
  French strings it saw on screen without a translation).

## API (`src/i18n`)

| Function | Use |
| --- | --- |
| `tr(fr)` | Translates one string (exact match). French mode returns it unchanged. |
| `tf(fr, ...args)` | Translates a **template**, then fills `{0}`, `{1}`… with `args` (inserted as is). |
| `tn(n, one, other, ...args)` | Plural-aware `tf`: picks the form with the language's rule (French: 0 and 1 singular; English: only 1), `{0}` = n. |
| `trAll(list)` | `tr` on every string of a list. |
| `trLine(line)` | Poem/note line: the whole line, or its body without a trailing `,` / `.` (« lumière, » → "light,"). |
| `translated(s)` | Marks a string assembled from translated pieces (`tf(…) + tr(…)`) as final, so a chokepoint does not report it as missing. |
| `hasTr(fr)`, `lang()`, `pick({ fr, en })`, `format(tpl, ...args)` | Helpers. `pick` is for per-language values (layouts, number formats). |
| `LANGUAGES`, `bindLanguage(get)`, `missing` | Option list, language source (bound to the settings in `main.ts`), strings missed this session (dev). |

In dev builds, a missing translation is logged once with `console.info('[i18n] missing en: …')` and collected in
`window.__veilleuse.i18nMissing()`. Production builds stay silent.

## Where translation happens (chokepoints)

These receive **French** and translate for display, so story and data files keep plain French strings and need **no
`tr()`**:

- Dialogue: `d.say` / `d.ask` / `d.narrate` text (each page), choices, speaker name tags (`SPEAKERS[x].name`), the
  `{time}` variable (`3h07` → `3:07`). `MINA_LINES` entries are looked up whole (`"text|happy"`) before the split.
- Scenes: chapter cards (`d.chapter(num, title, subtitle)`), image captions, `d.paper` lines and title (via `trLine`),
  `d.crash` lines, the phone (contact, clock, messages, statuses, prompt, replies), the shop (keeper, greeting,
  item names and descriptions), the poem scene (title, words), the sheep-count rounds, map banners (`MapDef.name`),
  `setPageTitle`, toasts, credits.
- Battle: `b.say`, bubbles (`talk`, `react*`, hook lines), list menus (items, targets, custom lists), `b.menuLabels`,
  notebook words (`WordDef.text`), enemy names (`EnemyRuntime.name`), the HUD, emotion names (`emotionLabel`,
  `soulLabel`, `emotionColorName`), `agree()`.
- Menus: item, weapon and outfit names and descriptions, souvenir titles, the gallery (titles, kinds, captions, poems).

**Display only.** Game logic keeps comparing French text and ids (`WordDef.text`, flags, `reactSpecial` keys, the
bot's `write:<word>`). Never compare a translated string; translate at the moment of display.

The final poem follows the same rule: `composePoem` builds French lines, saved as is (`flags.fin_poem`, the
gallery's `meta.poems`), and each line is translated with `trLine` when shown: the paper, the gallery, the shared
image and the epilogue, where Noa reads it aloud three words per page (`translated(…)` around the assembled page).

## What you must convert yourself

1. **Template literals with values** cannot be matched. Convert them to `tf` with numbered placeholders; the French
   template is the catalog key:

   ```ts
   // before
   await d.say(`Tu obtiens : {c:y}${def.name}{/c}.`);
   await b.say(`* ${e.name} n'est pas encore ${agree(e, 'apaisé')}.`);
   // after
   await d.say(tf('Tu obtiens : {c:y}{0}{/c}.', tr(def.name)));
   await b.say(tf("* {0} n'est pas encore {1}.", e.name, agree(e, 'apaisé')));
   ```

   - Arguments are inserted verbatim: wrap names coming from data with `tr()` (`EnemyRuntime.name` and `agree()`
     are already translated). Numbers and the player's name go in as they are.
   - English may reorder placeholders (`'{1}, {0}'`); each `{n}` of the key must appear in the value.
   - Plurals: `tn(n, '{0} Bouton', '{0} Boutons')` (two keys, both translated).
   - Gender: prefer two complete sentences (`e.def.fem ? tf('… apaisée …') : tf('… apaisé …')`) or `agree()`;
     English has its own entries (`'apaisé': 'calm'`, `'apaisée': 'calm'`).
   - Do not cut a sentence into pieces glued together: translators need whole sentences.
   - `{player}`, `{time}`, `{color}` and rich-text tags are not `tf` placeholders: keep them in the text.
2. **Text drawn directly** (`drawText`, `drawWrapped`, `drawOutlined` in a story overlay or an illustration) does not
   go through a chokepoint: wrap it with `tr()` / `tf()`.
3. **Assembled strings** (`line += …`): build each piece with `tr`/`tf`/`tn`, then pass `translated(line)`.
4. Strings that are not display text but look like it (debug labels, CSS, key names…) can be excluded from the
   coverage tool with `/* i18n-ignore */` or `// i18n-ignore` on the line, or `// i18n-ignore-start` … `// i18n-ignore-end`.

Format — plain data, one entry per line, single quotes, nothing computed:

```ts
/** English catalog — Chapter 1 (src/game/story/chapter1.ts). */
export const STORY_CHAPTER1: Record<string, string> = {
  'Il ne pleut que du coton.': 'It only rains cotton here.',
  'Chaussette, c\'est ma copine.|neutral': 'Sockette is my friend.|neutral',
};
```

Rules (checked by `tests/i18n.test.ts`):

- The key is the **exact** runtime French string: same punctuation, French spaces before `! ? : ;`, `« »`, `…`,
  `\n`, leading `* ` and trailing spaces.
- Keep every rich-text token, unchanged and as many times: `{c:y}…{/c}`, `{wave}…{/wave}`, `{shake}`, `{glitch}`,
  `{p:N}`, `{spd:x}`, `{player}`, `{time}`, `{color}`, `{0}`…
- Keep the `|expression` suffix of `MINA_LINES` entries, the `* ` prefix of battle lines and the number of `\n*` lines.
- Only characters of the bitmap font: use straight quotes `"` and `'` in English (no `“ ” ’`); `… — « » ·` and accents
  are fine.
- Battle buttons (all-caps keys) must fit their 70px buttons (≈ 6px per character, 11 characters at most).
- Keep lines about as long as the French (dialogue boxes paginate, but labels and HUD texts do not wrap).
- Do not define the same key twice with different values (a test fails); search the catalogs before adding one.
  Shared words (« Oui », « Non », « PV »…) already live in `ui.ts` / `battle.ts`.
- An empty value means "not translated yet" (the French is shown and the test reports it).

## Workflow for a translation pass

```sh
node tools/i18n-missing.mjs src/game/story/chapter1.ts                      # what is missing / dynamic
node tools/i18n-missing.mjs src/game/story/chapter1.ts --write src/i18n/en/story-chapter1.ts  # skeleton ('' values)
# convert the reported template literals to tf(), fill the values, register the file in src/i18n/en/index.ts
# then add the source file to src/i18n/manifest.json so the test keeps it complete
npx tsc --noEmit && npx vitest run && node tools/play.mjs "debug=script&name=c1_start&lang=en" out.png --steps auto
```

The extractor is a heuristic: string and template literals with letters and a space, an accented letter, an elision
(`l'aube`) or a capitalised/all-caps word. It skips imports, object keys, `x === '…'` comparisons, `case '…':`,
console/Error messages, ids, sprite keys, colors, key names, pixel grids and tag-only strings. Lowercase single words
without accents (`'bleu'`) are not detected: add those entries by hand when they are displayed.

The manifest (`src/i18n/manifest.json`) covers the UI/system files, the data files, the maps, `story/real.ts`,
`story/epilogue.ts`, `story/chapter1.ts`, `story/chapter2.ts`, `story/chapter3.ts` and `story/bonus.ts`. Still to translate: the other `src/game/story/*.ts`. `src/game/debug.ts` and the dev maps (`src/data/maps/test.ts`, `showcase_*.ts`) stay French
(developer tools).

Words (`WordDef.text`: notebook pools, `DODO_WORDS`, `MINA_WORDS`, `POEM_WORDS`, enemies' `specialWords`) are lowercase
single words the extractor cannot see: they live in `data.ts` and `tests/i18n.test.ts` checks that each one has an
entry. The words handwritten in Mina's drawings (`scrawl(g, tr('…'))` in `src/data/illustrations.ts`) are translated
when the static layer is painted; layers are cached per language.

## Adding a language

1. `Lang` and `LANGUAGES` in `src/i18n/index.ts`, `isLang`, the plural rule in `tn`, and `CATALOGS`.
2. A catalog folder `src/i18n/<id>/` with the same files (start from the English keys).
3. `Settings['language']` in `src/game/state.ts` (and its browser default), the boot-screen script in `index.html`.
4. Formats: `poemDate` (`src/game/ui/share.ts`), `{time}` (`src/game/ui/dialogue.ts`), the title-screen clock line.
5. Missing glyphs: add them to `src/engine/font-data.ts` (the font test lists them).

**Style.** Natural, simple, literary English for a touching and dark game (OMORI, Undertale): not a word-for-word
calque. Keep each voice: Noa's silences, Mina's cute bossiness, Dodo's softness turning possessive, the sheep's puns
(*baa*, wool, counting), Sockette's sock puns (pairs, darning, laundry). Keep the length close to the French.
